# 飞行无界

「飞行无界」是一个 AI Native 投资研究机构，本仓库为其官方网站源码。网站为纯静态页面，集合了机构介绍、研究报告与对外连接入口。

线上地址：<https://feixing.io>

## 网站内容

- **首页**（`index.html`）— 品牌介绍，说明「飞行无界」是谁、在做什么。
- **研究报告**（`research.html` 与 `research/` 目录）— 发布机构的投资研究报告，涵盖半导体、AI 大模型、美股七姐妹、港股等主题；子页面统一注入顶部导航条。
- **财经导航**（`links.html`）— 按类别整理的常用财经信息入口卡片。
- **关注我们**（`follow.html`）— 公众号 / 小红书入口与联系邮箱。

## 项目结构

```text
.
├── index.html       # 官网首页
├── research.html    # 研究报告列表页
├── follow.html      # 关注我们页面
├── links.html       # 财经导航页面
├── research/        # 研究报告子页面（独立 HTML）
├── resources/       # 静态图片资源（二维码等）
└── CHANGELOG.md     # 变更记录
```

网站为纯静态页面，无需安装依赖或构建步骤。
